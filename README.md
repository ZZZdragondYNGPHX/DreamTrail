# 昼梦途 · SolunaTrail

一款 Android 离线单机 **「昼夜专注与睡眠挂机 RPG」**。白天通过番茄定心或心流漫步推进探索，配合待办任务、呼吸调息与本地自然声景；夜晚与午休积累休息收益，探索 8 个区域，培养伙伴并搭配装备。

所有数据本地保存在设备上，纯单机离线运行，无需联网、账户、健康手环或定位权限，可通过 SHA-256 校验 JSON 存档备份和转移。

## 下载与游玩

从 [Releases](https://github.com/ZZZdragondYNGPHX/DreamTrail/releases) 下载 APK，支持 Android 8.0 及以上。

1. 在「旅程」切换 **「白昼专注」**（番茄定心 15/25/45/60m 或心流漫步正计时）或 **「夜间安眠」**（整夜安眠 / 午后小憩）。
2. 白昼专注解锁 **包容激励型定心加成（+3% ~ +10%）**、任务待办悬赏、茶歇奇遇，并产出 **「澄明墨晶」** 与 **「夜行筹备度」**；夜间好眠则提供 **「晨曦神采 / 小憩清思」** 反哺白昼效率。
3. 内置 **6 频道纯本地合成白噪音与自然声景**（雾林细雨、银滩潮声、火塘柴火、书斋钟摆、云巅风铃、沉静棕噪）、呼吸引导灯、可选翻转手机静心加成与「昼夜时光手账」7 日统计。
4. 在「角色」「伙伴」「营地」「图鉴」管理 8 阶装备、24 条词条共鸣、研习书斋建设、7 位伙伴和 16 只伴读小灵兽。

计时目标达成提醒在应用前台触发，离线收益返回应用后结算。本版面向全新安装，不迁移旧开发版数据。

## 游戏内容（v0.4.0 · Content & Rules v5）

- **8 个区域、24 条路线**：包含雾林至归梦星拱（1~6 境）及双栖进阶路线 **晴岚书院**、**晨曦钟塔**（7~8 境），48 种普通魔物与 8 位机制首领。
- **双核独立预算与平衡**：专注与休息各自拥有独立的滚动 24h 内 8h 上限；分心只影响额外定心祝福，基础收益保留。
- **40 件装备、24 种词条、4 大流派 4 阶星图、18 个被动**，人物等级上限升至 Lv.65。
- **6 座营地设施**：地图桌、工坊、旅舍、茶歇火塘（13 款安眠热茶与专注特调）、星尘花房、**研习书斋（Lv.1~5）**。
- **7 位伙伴（新增温言、朝露）、16 只伴读灵兽、16 篇午后茶歇奇遇与 16 篇晨间奇遇、12 件首领信物、30 项里程碑与 24 件风物**。

## 开发

技术栈：Kotlin、Jetpack Compose、Room；游戏规则为纯 Kotlin JVM 模块。

```text
app/       Android 界面、Room 持久化（Schema v5）、程序化声景与传感器辅助
core/      昼夜双核引擎、内容库、战斗、成长、离线结算与单元测试
docs/      架构与构建说明
gradle/    Gradle Wrapper 与依赖版本
tools/     本地 Android 构建与模拟器服务
```

使用 JDK 21 和 Android SDK 36：

```bash
./gradlew :core:test :app:testDebugUnitTest :app:assembleDebug :app:lintDebug
```

Linux 下开发通过独立 systemd 服务运行 Android 任务：

```bash
bash tools/android-service.sh build
```

详细说明见 [构建与发布](docs/development.md) 和 [架构](docs/architecture.md)。
